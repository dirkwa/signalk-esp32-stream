# Contributing

This is a personal project and currently private, so contributions are unlikely
— but the terms are stated here so they are settled if that changes.

Build before opening a PR:

```bash
npm run build   # tsc
```

There is no test suite or CI yet. Commits follow
[Angular conventional commit](https://www.conventionalcommits.org/) format, and
branch names use hyphens rather than slashes.
